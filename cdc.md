# PROJET D'ÉVALUATION – JavaScript Avancé
## Application Web de Gestion de Bibliothèque

---

## Encadrement

**Encadrant / Tuteur :** Mouhamed Moustapha Diouf

---

## 1. Objectif du projet

Ce projet a pour objectif de permettre aux étudiants de développer une application web interactive de gestion de bibliothèque en utilisant HTML, CSS, JavaScript et XML.

---

## 2. Durée estimée du projet

La durée estimée pour la réalisation du projet est de **3 semaines**.

---

## 3. Compétences évaluées

- Manipulation du DOM
- Gestion des événements
- CRUD en JavaScript
- Chargement XML
- Logique applicative front-end

---

## 4. Structure du projet

```
projet-gestion-bibliotheque/
├── index.html
├── style.css
├── script.js
├── books.xml
└── docs/
└── images/
```

---

## 5. Fonctionnalités

- **Affichage :** Chargement XML et affichage en tableau
- **Ajout :** Ajout dynamique de livres via formulaire
- **Modification :** Mise à jour des informations
- **Recherche :** Filtrage par titre
- **Modal :** Affichage détaillé d'un livre

---

## 6. Technologies utilisées

- HTML5
- CSS3 (Responsive + UI moderne)
- JavaScript (Vanilla)
- DOM Manipulation
- XML + XMLHttpRequest
- VsCode + Live Server *(extension VSCode pour serveur local)*
